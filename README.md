# 퍼스트앤베스트의원 홈페이지

`index.html` 파일을 브라우저로 열면 바로 볼 수 있습니다.

## 수정하는 방법 (원장님용)

Claude에게 말로 요청하시면 됩니다. 예시:

- "전화번호 02-000-0000 넣어줘"
- "네이버 예약 링크는 https://… 야"
- "원장 이름은 홍길동, 학력은 ○○대학교 의과대학 졸업이야"
- "주사 시술에 ○○ 추가해줘"
- "울쎄라 가격 ○○만원으로 바꿔줘"
- "써마지 설명 검토 끝났어" → [원장 검토 필요] 표시가 사라집니다
- "메인 문구를 '첫 상담의 정성을, 마지막 관리까지'로 바꿔줘"
- "피부 나이 퀴즈 3번 질문을 ○○로 바꿔줘"
- "퀴즈 검토 끝났어" → 퀴즈 화면의 [원장 검토 필요] 표시가 사라집니다
- "인스타에 올릴 퀴즈 홍보 글 만들어줘" → 초안만 만들어 드려요. 의료광고 사전심의를 받은 뒤 원장님이 직접 올려 주세요

## 어디에 무엇이 있나요

- `data/clinic.js` — 병원 정보 (문구, 링크, 전화, 주소, 진료 시간, 원장 소개)
- `data/treatments.js` — 시술 목록과 가격 (시술 안내·비급여 진료비 표가 여기서 자동 생성)
- `images/` — 사진 (지금은 임시 이미지)
- `quiz.html` — 피부 나이 퀴즈 페이지 (질문·결과 문구는 `data/quiz.js`)
- `images/og-quiz.png`, `images/og-home.png` — 카카오톡·SNS에 링크를 붙였을 때 보이는 미리보기 그림
- `CLAUDE.md` — 홈페이지 수정 시 지켜야 할 규칙 (의료광고 금지 표현 등)

## SNS → 퀴즈 → 예약 흐름

1. SNS 글(인스타 프로필 링크·스토리 링크 스티커, 스레드·X 글의 링크)로 `quiz.html`에 들어옵니다.
2. 질문 9개에 답하면 **짧은 요약**(피부 시계 단계, 점수, 먼저 챙길 습관, 고른 고민)이 바로 나옵니다.
3. **자세한 결과 확인하기**를 누르면 습관별 이유와 근거, 고민별 시술 안내와 부작용 안내, 진료비 표, 네이버 예약·카카오톡 상담 버튼이 이어집니다.

- 진료비는 `data/treatments.js`의 가격이 자동으로 들어갑니다 (가격이 정해지면 홈페이지 비급여 표와 퀴즈 결과가 함께 바뀝니다).
- 패키지(묶음) 가격·할인은 넣지 않습니다 (의료법 제27조 제3항 환자 유인 우려).
- SNS 게시물은 의료광고 사전심의 대상입니다. 심의 전 광고물이 공개되지 않도록 SNS용 이미지·글 초안은 이 저장소에 넣지 않습니다.
