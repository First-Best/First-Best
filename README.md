# 퍼스트앤베스트의원 홈페이지

`index.html` 파일을 브라우저로 열면 바로 볼 수 있습니다.

## 수정하는 방법 (원장님용)

Claude에게 말로 요청하시면 됩니다. 예시:

- "전화번호 02-000-0000 넣어줘"
- "네이버 예약 링크는 https://… 야"
- "원장 이름은 홍길동, 학력은 ○○대학교 의과대학 졸업이야"
- "주사 시술에 ○○ 추가해줘"
- "울쎄라 가격 ○○만원으로 바꿔줘"
- "써마지 설명 검토 끝났어" → [원장 검토 필요] 표시가 사라집니다
- "메인 문구를 '첫 상담의 정성을, 마지막 관리까지'로 바꿔줘"

## 어디에 무엇이 있나요

- `data/clinic.js` — 병원 정보 (문구, 링크, 전화, 주소, 진료 시간, 원장 소개)
- `data/treatments.js` — 시술 목록과 가격 (시술 안내·비급여 진료비 표가 여기서 자동 생성)
- `images/` — 사진 (지금은 임시 이미지)
- `CLAUDE.md` — 홈페이지 수정 시 지켜야 할 규칙 (의료광고 금지 표현 등)
